# VOLUNELLE

VOLUNELLE is a luxury journal-building studio created by Crown&Craft Studio. It is built with plain HTML, CSS, and JavaScript and includes journal artwork uploads, monthly page generation, PDF and GoodNotes export, internal month navigation, fillable entry pages, and mobile PNG sharing.

## Run locally

```powershell
node serve.mjs
```

Open `http://127.0.0.1:5174/` in a browser.

No build step or framework installation is required.
